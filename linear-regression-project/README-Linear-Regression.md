# Linear Regression from Scratch

A simple implementation of Linear Regression from scratch using NumPy, and comparison with sklearn.

**What is included**
1. Simple Linear Regression Theory
2. Multiple Linear Regression Theory
3. Least Squares / Normal Equation Thoery
4. Model prediction
5. MSE and R² evaluation
6. Multicolinearity: VIF
7. 3D visualization of the regression surface

File
Linear_regression_example.ipynb — complete implementation and visualization.
