# Linear Regression Theory

Linear regression is a supervised learning algorithm used to model the relationship 
between a dependent variable and one or more independent variables to predict continuous outcomes.

The core idea is to fit a best-fit line through the data points that minimizes 
the difference between actual and predicted values. 

***Independent variable*** (input) is the factor we control or observe

***Dependent variable*** (output) is the factor that depends on the independent variable

**Best Fit Line:**
The best-fit line is the straight line that best represents the relationship between the independent variable (input) and the dependent variable (output). 
The goal is to minimize the difference between the actual data points and the predicted values generated by the model.

the best fit line is represented by the equation:

y = mx + b

where m is the slope, b is the intercept, x is the input feature, and y is the predicted output 

***The working of linear regression in machine learning can be broken down into many steps as follows*** −

**Hypothesis** − We assume that there is a linear relation between input and output.

**Cost Function** − Define a loss or cost function. The cost function quantifies the model's prediction error. 
The cost function takes the model's predicted values and actual values and returns a single scaler value that represents the cost of the model's prediction.

**Optimization** − Optimize (minimize) the model's cost function by updating the model's parameters.

Minimizing the Error using the Least Squares Method:

To determine the best-fit line, linear regression uses the Least Squares Method, which minimizes the difference between actual and predicted values. These differences are called residuals. These differences are called residuals.

The formula for residuals is:Residual =

yᵢ is the actual observed value
​y^ᵢ is the predicted value from the line for that 

## There are 2 types in Linear Regression Method.
*  Simple Linear Regression
*  Multiple Linear Regression

**Simple Linear Regression:** Models the relationship between a single independent variable and a dependent variable 

**Multiple Linear Regression:** Incorporates multiple independent variables to predict a continuous outcome,
 assigning coefficients to each feature to reflect its impact. 

the model extends to multiple features:
y = b + w₁x₁ + w₂x₂ + ... + wₙxₙ

where each wᵢ represents the weight of the corresponding feature 

The model is trained by minimizing the error between predicted and actual values, 
often using the Least Squares Method, which minimizes the sum of squared residuals (differences between actual and predicted values), 

### Applications

* ***Predictive Modeling:*** Estimating house prices based on features like size and location 

* ***Trend Forecasting:*** Predicting sales or stock trends over time 

* ***Risk Assessment:*** Evaluating factors that influence outcomes, such as medical risk scoring 

* ***Decision Making:*** Supporting business or financial decisions by predicting continuous outcomes

**Implementation in Python**
Python libraries like scikit-learn and SciPy provide built-in methods to implement linear regression. 

**The workflow typically involves:**

* Loading and splitting the dataset into training and testing sets.

* Fitting a linear regression model to the training data.

* Predicting outcomes on test data.

* Evaluating performance using metrics like Mean Squared Error (MSE) or R² score
